# E-Commerce Sales Analysis & Power BI Dashboard

## Project Overview
This project analyzes 50,000 e-commerce orders to understand sales performance, revenue trends, customer segments, and order status.

## Tools Used
- PostgreSQL and SQL
- Microsoft Excel
- Power Query
- Power BI and DAX

## Work Performed
- Cleaned and transformed data using Excel and Power Query.
- Queried customer, order, product, and payment tables using SQL.
- Used JOINs, aggregations, CTEs, subqueries, and window functions.
- Created DAX measures for revenue, Average Order Value (AOV), completed orders, completion rate, and unique customers.
- Built an interactive Power BI dashboard with category, city, customer segment, payment method, product, and order status analysis.

## Key Skills Demonstrated
SQL querying, data cleaning, data transformation, KPI calculation, data modeling, and dashboard development.
